# ONEXUS – Relationship Layer (Revit Add-in Companion Viewer)
Interactive Graph Visualization for BIM Element Relationships

ONEXUS is a lightweight, browser-based visualization layer designed to make BIM relationships visible, explorable, and explainable. It complements your Revit add-in by rendering system, spatial, and responsibility relationships as a Cytoscape.js graph with rich interaction, filtering, and export capabilities.

## Key Capabilities
- Interactive Graph Engine
- Multiple Layout Modes
- Multi-Language Support
- Lightweight JSON Schema
- Filtering & Exploration Tools
- Modern UI with Themes
- Import / Export

## Running the Viewer
Open index.html or serve locally.
